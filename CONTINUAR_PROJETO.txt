O QUE É ESTE APP
----------------
É um app Android para o projetor. Ele monitora há quanto tempo o projetor está
ligado, avisa quando chega a hora de descansar, permite lembretes de horário,
pessoas/perfis e mostra relatórios de uso.

O QUE O APP FAZ HOJE
--------------------
- Mostra a hora e o tempo restante sem segundos.
- Usa ícone de relógio no horário atual e ampulheta no tempo restante.
- Avisa em tela grande quando o tempo de uso acaba.
- Mostra quanto tempo o projetor ficou ligado e quanto tempo deve descansar.
- O aviso pode tocar som repetido até ser fechado.
- Voltar fecha o aviso, mas o monitoramento continua por trás.
- Há modo de teste para conferir os avisos sem esperar o tempo real.
- Tem pessoas/perfis, lembretes por horário, lembretes gerais e relatórios.
- Pode procurar e instalar atualização do próprio app pelo GitHub.

COMO FAZER UMA ATUALIZAÇÃO NOVA
-------------------------------
1. Edite o projeto nesta pasta oficial no Android Studio.
2. Teste no projetor pelo Android Studio se possível.
3. Abra o GitHub Desktop e confirme que ele está apontando para este projeto.
4. No GitHub Desktop: escreva um resumo, clique em Commit to main e depois em
   Push origin.
5. Só use Pull origin se o GitHub Desktop avisar que existem mudanças no GitHub
   que ainda não estão no computador. A ordem normal é: Commit, Push.
6. Entre no GitHub no navegador, abra o repositório e vá em Actions.
7. Abra o fluxo “Gerar APK de atualização”.
8. Clique em Run workflow, coloque a nova versão (exemplo: v1.13) e confirme.
9. Espere aparecer Success.
10. Abra Releases e baixe o arquivo TemporizadorV2.apk da versão nova.
11. Instale o APK por cima da V2 no projetor.

ATUALIZAÇÃO AUTOMÁTICA NO PROJETOR
----------------------------------
Quando uma versão mais nova existe no GitHub, o app V2 procura atualização ao
abrir. Ele mostra a opção de baixar; depois o Android pede confirmação para
instalar. Nada é instalado escondido sem confirmação do Android.

GITHUB ACTIONS E SEGREDOS
-------------------------
O GitHub monta um APK assinado usando os Secrets do repositório. Nunca colocar
senhas, códigos ou chaves dentro deste projeto, em mensagem, ou em arquivo TXT.
Se os Secrets forem apagados, a geração de APK assinado pelo GitHub precisará
ser configurada novamente.
